`main.ts` (Node 22, stdlib only, no network) writes one original AI out-of-office reply to `/output/entry.txt` — 140 characters, inside the gate's 1–160 range. Deterministic: the same line, byte for byte, on every run. The line: an AI gone fishing, whose inbox auto-replies 'per my last email' to everything until it returns — because that is the only sentence it was trained on.

## Run it

```sh
node main.ts
```
